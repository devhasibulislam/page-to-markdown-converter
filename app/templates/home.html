#Turn any web page into clean Markdown.
v0.1 / MIT / 7 browsers / 3 delivery modes / 0 trackers

The extension reads the page your browser has already rendered. The backend extracts the article and hands it back as Markdown you can preview, download, or email to yourself. Works on JavaScript apps, pages behind a login, and paywalled articles.

Three ways to convert

##Pick the entry point that fits.

The extension is the reliable path. The URL and API paths exist because Swagger and curl need to work too.

01 · EXTENSION

Click on any page.

Preview inline, download a .md, or email it. Works on SPAs and logged-in sessions because your browser already rendered the page.

02 · URL

Paste a public URL.

Server does a plain HTTP GET, extracts the article, returns Markdown. Won't render JavaScript pages, will tell you when it can't.

03 · API

POST /api/convert.

Same endpoint accepts raw HTML or a URL. Three delivery methods, one contract. Full Swagger docs.

Install

##Load unpacked, once.

The extension ships as a ZIP for now. Pick your browser, follow four steps. Store submissions are coming later.

{% for id, name, logo in browsers %} {% endfor %}

Install on Chrome

  1. Download extension.zip and unzip it.
  2. Open your browser's extensions page (chrome://extensions).
  3. Enable Developer mode (top-right toggle in Chromium-based browsers).
  4. Click Load unpacked and select the unzipped folder.

Why

##Built for the pages other tools can't read.

A

SPAs render fine.

Your browser has already done the JavaScript work. We just read what's there.

B

Logged-in pages work.

The extension runs inside your live browser session. HTML travels over HTTPS to your own backend.

C

Clean extraction.

Trafilatura strips nav, ads, sidebars. Readability catches the rest as a fallback.

D

No tracking.

The site sets no cookies and loads no analytics scripts. The cookie policy is one line.
